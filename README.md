# Spore2xCreatureDinoExtension

About:

A mod that increases the amount of time it takes for certain drama events to happen in Spore's Creature Stage, as well as the time it takes for creatures to evolve and how many creatures you need to kill to make them extinct. This is meant to serve as an extension to the Creature Stage Extender mod created by https://github.com/Kyrfuffle/Creature-Stage-Extender, and should be used with the 2x Creature Extender for best effect.
